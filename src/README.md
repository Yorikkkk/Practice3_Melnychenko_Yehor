# Контрольні питання та відповіді
## Лабораторна робота №3: Управління потоком виконання

### 1. Що таке структурне програмування?
Це парадигма розробки програмного забезпечення, яка базується на представленні програми у вигляді ієрархічної структури блоків та відмові від хаотичних переходів (оператора goto).

---

### 2. Назвіть основні конструкції структурного програмування.
- Послідовність (Sequence) — виконання команд одна за одною.
- Розгалуження (Selection) — вибір гілки виконання (if, switch).
- Повторення/Цикл (Iteration) — повторення дій (while, do-while, for).

---

### 3. Назвіть основні принципи структурного програмування.
- Модульність (розбиття системи на окремі функції/методи).
- Проектування «зверху-вниз» (Top-Down Design).
- Використання лише базових керуючих конструкцій (послідовність, вибір, цикл).
- Кожна підпрограма/блок має один вхід та один вихід.

---

### 4. Поясніть, чому в більшості мов програмування не радять використовувати оператор GOTO, а в мові Java його взагалі немає?
Використання goto робить хід виконання програми плутаним і складним для аналізу («спагеті-код»). У Java goto збережено як зарезервоване слово (ключове слово, яке не можна використовувати як назву змінної), але сам оператор не реалізований для забезпечення надійності та читабельності коду.

---

### 5. Що таке спагеті-код?
Це код із заплутаною та неструктурованою логікою виконання (часто через велику кількість безумовних переходів, глибоку вкладеність умов та відсутність модульності), який важко читати, тестувати та підтримувати.

---

### 6. Що таке проектування зверху-вниз? В чому його переваги?
Це метод розробки, при якому загальна задача спочатку розбивається на декілька великих підзадач, які надалі деталізуються до рівня простих методів.
- Переваги: чітка структура, спрощення налагодження, легкість розподілу завдань між розробниками.

---

### 7. Що таке область видимості ідентифікатора?
Це частина програми (блок, метод або клас), у межах якої змінна чи метод доступні за своїм ім'ям.

---

### 8. Що таке блок? Як блоки впливають на область видимості?
Блок — це група операторів, взята в фігурні дужки { ... }. Змінні, оголошені всередині блоку, є локальними та доступні тільки всередині цього блоку та його вкладених блоків (і знищуються при виході з блоку).

---

### 9. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
- if: перевірка єдиної умови (наприклад, if (x < 0) throw new IllegalArgumentException();).
- if-else: вибір між двома взаємовиключними варіантами (наприклад, парне/непарне число).
- ланцюги if-else if -else if...: перевірка діапазонів чи багатьох послідовних умов (наприклад, визначення оцінки за балами).
- switch: вибір з багатьох точних дискретних значень (наприклад, обробка днів тижня або команд меню).
- тернарна умовна операція ?: : коротке присвоєння значення залежно від умови (наприклад, int max = (a > b) ? a : b;).

---

### 10. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
- while: коли кількість ітерацій невідома заздалегідь і цикл може не виконатися жодного разу (наприклад, обчислення суми ряду до досягнення точності epsilon).
- do-while: коли тіло циклу має гарантовано виконатися хоча б один раз (наприклад, повторне введення даних користувачем до введення коректного значення).
- for: коли кількість повторень відома заздалегідь (наприклад, перебір елементів від 1 до k).

---

### 11. Чим оператор break відрізняється від оператора continue?
- break — достроково повністю перериває виконання всього циклу чи switch.
- continue — пропускає залишок поточної ітерації циклу та одразу переходить до наступної ітерації.

---

### 12. Навіщо у мові Java є мітки, якщо немає goto?
Мітки (labels) використовуються разом із break та continue для виходу або переходу на наступну ітерацію зовнішнього (вкладеного) циклу, а не довільного місця в коді.

---

### 13. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.

Фрагмент коду:
boolean a = false;
boolean b = false;        
if (a=false) {
System.out.println("a is false");
}
if (b=true) {
System.out.println("b is true");
}
if (a=b) {
System.out.println("a = b");
}

Результат:
b is true
a = b

Пояснення:
- if (a=false) — відбувається присвоєння значення false змінній a. Результатом операції присвоєння є саме значення false, тому перша умова не виконується.
- if (b=true) — відбувається присвоєння true змінній b. Результатом виразу є true, тому виконується перший друк: "b is true".
- if (a=b) — значення змінної b (яка тепер true) присвоюється змінній a. Вираз обчислюється як true, тому виконується другий друк: "a = b".

---

### 14. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.

Фрагмент коду:
int a = 1;
a++;
++a;        
switch(a) {
case 1: System.out.println("1");
case 2: System.out.println("2");
case 3: System.out.println("3");
case 4: System.out.println("4");            
}

Результат:
3
4

Пояснення:
1. Початково a = 1.
2. Після a++ значення стає 2.
3. Після ++a значення стає 3.
4. Оператор switch(3) робить перехід на case 3: і виводить "3".
5. Оскільки у блоках case відсутній оператор break, відбувається сквозне виконання (fall-through), і програма продовжує виконувати наступні інструкції, друкуючи також "4".

---

### 15. До якого результату призведе виконання наступного фрагменту коду (true/false)? Перевірте. Поясніть.

Фрагмент коду:
double sum = 0;                
// Let's find: 1 + 1/2 + 1/3 + 1/4 + 1/5 + ...
for(int i=1; i<10; i++) {
sum = sum + 1/i;
}
System.out.println(sum > 1);

Результат:
false

Пояснення:
У виразі 1/i обидва операнди є цілими числами типу int. Відповідно, Java виконує цілочисельне ділення:
- При i = 1: 1/1 = 1.
- При i = 2, 3, ..., 9: дробова частина відкидається, тому 1/i = 0.

У результаті sum дорівнює 1.0. Перевірка умови sum > 1 (тобто 1.0 > 1) повертає false. Для того щоб обчислювалася справжня математична сума, потрібно було написати 1.0 / i.
